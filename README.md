# 史间 · 微信式历史社交原型（v2.0 · 史记扩充版）

## 本轮更新
- **时空年轮（参考「历史年轮」App）**：朋友圈底部新增可拖动年轮，圆点即"时间驿站"（有动态的年份 / 重大事件年份）；支持 `▶ 播放` 自动逐站穿越、`‹ ›` 逐站步进、时代快捷跳转（春秋 / 战国 / 秦与秦末 / 楚汉 / 西汉 / 北宋……）、键盘 ←/→ 步进。不了解历史的玩家按播放即可"看着时间流动"，看到感兴趣的内容随时暂停。
- **本年大事卡**：进入某年份时，动态流顶部显示该年大事与史料出处；所选年份无记载时自动回退展示最近的年份并明确提示。
- **《史记》内容大幅扩充**：新增司马迁、项羽、刘邦、韩信、陈胜、孔子、勾践、蔺相如、廉颇、屈原、荆轲、李广等人物档案、动态（含《垓下歌》《大风歌》《易水歌》等原文与出处）、大事年轮与聊天脚本。每条动态标注系年凡例：原文系年 / 传统系年 / 演绎换算 / 演绎。
- **数据与 UI 彻底分离**：内容全部在 `data/`，界面在 `index.html` + `js/`；数据层提供统一适配器接口，预留 AI Agent 接入点。

## 运行
直接在浏览器打开 `index.html` 即可，无需服务器或依赖。
（若使用 fetch 型异步适配器则需要本地静态服务器：`python3 -m http.server`。）

## 目录结构
```
shijian/
├── index.html          # UI 壳（无任何硬编码内容）
├── css/styles.css      # 样式
├── js/
│   ├── store.js        # 数据层：查询 / 检索 / Agent 适配器接口
│   ├── timeline.js     # 时空年轮组件（拖动 / 驿站 / 播放）
│   └── app.js          # 页面逻辑（只调 Store，不碰原始数据）
└── data/               # 全部内容数据（window.SHIJIAN_DATA.*）
    ├── meta.js         # 版本 / 时间轴范围 / 时代分段
    ├── people.js       # 人物档案（生卒年、简介、来源）
    ├── moments.js      # 朋友圈动态（含史记原文与系年凡例）
    ├── events.js       # 大事年轮（驿站节点）
    ├── chats.js        # 聊天互动脚本
    ├── storycalls.js   # 时空连线（剧情视频通话脚本：四集 + 抉择 + 史册）
    ├── fanfics.js      # 二创 · 演绎（独立文件，fanfic:true）
    └── translations.js # 文言 → 白话对照表
```

## 时空连线（剧情视频通话）
- 入口：聊天页输入框旁「＋」→「时空连线」→ 集数列表（1、2、3…顺序解锁）。
- 点开一集 = 一通跨时空视频通话：上半屏视频区（预留场景背景位 + Q版人物位），下半屏对白逐条蹦出；抉择点用快捷回复回应，也可自由打字（脚本兜底，接 Agent 后真人化）。
- 史实锁死：任何选择都收敛回同一历史走向，分支只改变「TA 对你说的私房话」；幕末解锁「史册」考据卡（原文锚点 + 凡例）。
- 集序：帷幕 → 折 → 至暗 → 余响；读完第 N 集解锁第 N+1 集；读完四集解锁该人物「二创 · 演绎」聊天。
- 进度存 localStorage（`shijian.progress.v1`，键沿用幕 id）；朋友圈碎片层（动态归档）保留不变，剧情层与碎片层互相独立。

## 数据文件
people / moments / events / chats / translations / **storycalls（剧情视频通话脚本）** / **fanfics（二创，独立文件）**
- 二创红线：fanfic 永不进入正史数据文件；UI 常驻"二创 · 演绎"标记。

## AI Agent 接入点（js/store.js）
实现一个适配器对象并注册即可整体替换数据源，UI 无需改动：
```js
ShiJianStore.useAdapter({
  meta() {...}, eras() {...}, people() {...}, person(id) {...},
  events() {...}, moments() {...}, chats() {...}, translations() {...},
  storycalls() {...}, fanfics() {...}
});
```
方法允许返回 Promise；完成后可 `window.dispatchEvent(new Event('shijian:data'))` 通知 UI 重渲染。典型用法：由 Agent 按 `{year, person, style}` 动态生成动态与回复，或把 `translations()` 换成实时文言翻译服务。

## 已知边界
- 纯前端演示：点赞、评论、聊天均为本地状态，不落盘。
- 《史记》动态的月日多为演示换算（每条 note 已标注）；正式版需逐条核验历法换算。
