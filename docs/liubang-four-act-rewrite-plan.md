# 刘邦角色来电剧情四幕重写计划

状态：第二至第四幕正文（入咸阳与约法、鸿门脱身、沛宫作歌）已按本计划的分析与细纲写入 `data/storycalls.js`，与重写后的第一幕构成完整四幕，等待用户审阅。项羽是唯一已确认范本；本计划只迁移其戏剧方法，不复制其口头禅、事件组织、人物气质或句式。

## 重写目标

让不了解秦末史的玩家，通过四通有连续关系的电话认识刘邦：他怎样让人愿意跟随、怎样兑现对人的承诺、怎样在危急中借助别人活下来，以及得到权力后怎样面对自己对能人的需要和戒心。人物弧不预设为“好人变坏人”，而让玩家看见同一种长处在不同权力位置上如何带来相反后果。

旧稿的主要问题是把“支持／阻止／追问”写成角色问玩家赞不赞成，再用选项回答问卷；又把每幕的分析项做成明显的台词提纲。新稿先写当下行动和关系，再从角色真实需要里长出玩家回应，不规定每组必须三选项，也不要求每幕都按同一节拍转折。若一处选择不能改变人物对玩家的回应、透露的信息或现场行动，就重写该处。

## 史料核对入口

- [《史记·高祖本纪》卷八](https://zh.wikisource.org/wiki/史記/卷008)：丰西泽纵徒、秦王降后入咸阳、还军霸上与约法三章、沛宫作歌及高祖当年所知的诸侯叛乱记录。
- [《史记·项羽本纪》卷七](https://zh.wikisource.org/wiki/史記/卷007)：鸿门宴席、樊哙闯帐、刘邦脱身、张良留谢与刘邦回军后诛曹无伤。

现阶段确认的是上述事件锚点。角色当时的羞惧、贪恋、怀疑、记恩或对能人的戒心，属于需要在正文中谨慎演出的解释，不能冒充《史记》对其内心的直接记录。

## 跨幕关系线

第一幕把众人的去留交还给他们，刘邦第一次从“我也无路可退”走到“有人自愿留下”。第二幕让这份追随进入咸阳秩序：不拿百姓东西、公布约法是否只是笼络人心，取决于刘邦能否约束自己人。第三幕把依靠与防备同时摆上桌：张良替他留在鸿门，曹无伤却把军情卖给强者；刘邦既记得谁救过自己，也迅速处理威胁。第四幕从沛宫宴席回看前面几次选择：他仍需要敢做事的人，却越来越难安放不完全受控的人。该弧线是编剧假设；要通过当时可见的选择和史料检验，不写成刘邦对自己一生的后见总结。

## 四幕细纲

以下是场景顺序和戏剧功能，不是对白稿。每幕还需逐场回查史料、补充有争议处；玩家反应的示例只说明互动功能，不是规定每幕必须放支持、反对、追问三类。

### 第一幕：丰西泽放徒

1. **开场现场**：夜行押送途中不时有人逃散。刘邦停下队伍、点酒，听见草丛里又有动静。玩家从眼前的逃亡和刘邦没追这一动作理解麻烦，不先听一段秦法介绍。
2. **来电关系**：刘邦把自己准备说的话讲给玩家听，带点醉意和玩笑，实际在试探玩家会不会把他当成只想逃罪的人。通话目的通过试话和躲闪显露，不让他直接汇报“我想确认我的动机”。
3. **第一轮介入**：刘邦打算释放余下刑徒。玩家可以先顾眼前人的生路、提醒刘邦他也在把别人卷入危险，或追问刑徒逃亡缘由。回应要影响刘邦接下来如何开口，而不是改变史实。
4. **说出选择**：刘邦向众人说明他不会再押送，也不回县；众人可以离开。重点放在他把选择权交出去时的迟疑，以及他无法保证留下者会有活路。
5. **结果与反差**：大部分人离去，仍有人留下。刘邦不把他们立刻解释成拥戴者；先问清他们为什么不走，至少有人答“回去也是死，不如看看你往哪走”。
6. **收束**：他们开始同行，前方蛇与夜路让风险继续可见。刘邦承担带路，而不是宣布自己有了追随者。留下下幕能承接的不是抽象口号，而是“这些人跟了他以后，他要拿什么对他们负责”。

### 第二幕：入咸阳与约法

1. **开场现场**：营中传来宫门、软榻或府库的具体消息，刘邦刚从秦宫退回霸上。用一件他舍不得放下的物件或被打断的休息表现贪恋和不满，不先替他复盘“先入关”。
2. **把权力带进场景**：百姓把酒食送到营外，却停在火光之外；军士也在等命令。刘邦意识到人们不知道换了谁掌权，日子会不会仍旧一样。
3. **玩家介入**：玩家可以替他挡住自我辩护，提醒“退出宫室”本身不等于军队守规矩；也可以理解他不甘心，或问百姓具体怕什么。刘邦不能马上用“约法三章”作标准答案。
4. **处置小事件**：出现军士拿取馈赠、秦吏询问旧法是否照行，或百姓试探军纪等具体冲突。选定一个主场事件，避免把府库、辞食、封门、三章全部压成事件清单。刘邦要当场作出一项能被旁人看见的决定。
5. **从决定到约法**：萧何或张良指出单次制止不够，百姓需要知道以后按什么办。约法的形成通过讨论和宣示进入；玩家可以问规则能否约束刘邦自己人，或提醒百姓需要的是可预期的处置。
6. **收束**：有人第一次走进营门或接受约法，但信任尚未稳固。函谷关方向的军报带来项羽将至的现实压力；刘邦要带着刚立下的约束面对更强军队。

### 第三幕：鸿门脱身

1. **开场现场**：刘邦刚逃回霸上，马汗未干；营中有人庆贺，刘邦却不断望向营门，张良还留在鸿门善后。用身体反应和对张良迟迟未归的关注呈现后怕。
2. **关系而非战报**：玩家陪他等消息。鸿门宴的信息通过刘邦眼下记住的一个动作、一个座次、一句当面说的话逐渐浮出；不复述整场宴席，不要求玩家认识范增、项伯等人的全部关系网。
3. **玩家介入**：刘邦可以谈自己借如厕脱身，也可以掩饰窘迫。玩家的回应应作用于两件具体事：他为何仍然赴宴，以及他是否承认靠了项伯、张良、樊哙的帮助。避免让角色把“我能屈能伸”当成总结。
4. **危机转向**：曹无伤求见，刘邦得知/确认告密者是谁。故事从“我怎么活下来”转到“谁替自己的利益出卖全军”。玩家可支持立即处置、要求当面听他说明，或追问刘邦为何如此看重这次背叛；这些回应改变通话关系和刘邦的解释，不改诛杀史实。
5. **人物选择**：张良安全回来后，刘邦放下等人的焦虑，随后下令处置曹无伤。让命令和先前“把去留交还众人”的行为并置，由玩家指出相似或矛盾处；不要由旁白判定刘邦双标，也不让刘邦自己概括一生。
6. **收束**：张良归来带来实际松弛，但曹无伤之死留下更难回避的问题：刘邦记恩与除患如何同时存在。下幕转到他拥有更大权力后，这种张力会带来什么代价。

### 第四幕：沛宫作歌

1. **开场现场**：酒宴正热，刘邦的箭伤发作；孩子们练歌唱到第三句停住。刘邦让玩家先听，不急着交代整首歌和回乡经过。
2. **重逢不等于回到从前**：父老、旧友按君臣礼节行礼，刘邦叫他们不必多礼，反使场面更拘谨。通过一次具体称谓或无人敢坐的空位，让玩家感到“故乡仍在，旧位置已不存在”。
3. **玩家介入**：玩家可以陪他接着唱、指出他不必把眼泪说成酒意，或追问第三句里要找谁守四方。回应让刘邦选择继续唱、停下或谈一个具体的人，不替他抽象解释乡愁。
4. **猛士的现实代价**：歌声/席间谈话使“守四方”碰到他眼前的将领、信任和用兵问题。提及韩信、彭越等人时只说刘邦当时已知且与当前情绪有关的事实，不做名单式点名或生平总结；复核诛杀责任、史料叙述与人物当下认知的边界。
5. **回看第一幕**：某个由玩家选过的判断或关系动作回到当下，例如“让人自己选”曾经是他带人的办法，如今他是否还允许有功之人保有自己的选择。此回响必须由玩家此前确实说过的话触发，不能凭空假设每个分支都选了同一句。
6. **收束**：刘邦做一件当下可见的事回应“如何留人”：对父老兑现免赋之约、把歌教给孩子，或承认某个问题他答不上来后仍让孩子唱下去。具体结尾须在查实史料与场景可行性后选择，不加半年后死亡或后世政局旁白。
