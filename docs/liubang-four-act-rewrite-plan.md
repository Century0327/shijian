# 刘邦角色来电剧情四幕重写计划

状态：计划，未写正文。项羽是唯一已确认范本；本计划只迁移其戏剧方法，不复制其口头禅、事件组织、人物气质或句式。

## 重写目标

让不了解秦末史的玩家，通过四通有连续关系的电话认识刘邦：他怎样让人愿意跟随、怎样兑现对人的承诺、怎样在危急中借助别人活下来，以及得到权力后怎样面对自己对能人的需要和戒心。人物弧不预设为“好人变坏人”，而让玩家看见同一种长处在不同权力位置上如何带来相反后果。

旧稿的主要问题是把“支持／阻止／追问”写成角色问玩家赞不赞成，再用选项回答问卷；又把每幕的分析项做成明显的台词提纲。新稿先写当下行动和关系，再从角色真实需要里长出玩家回应，不规定每组必须三选项，也不要求每幕都按同一节拍转折。若一处选择不能改变人物对玩家的回应、透露的信息或现场行动，就重写该处。

## 跨幕关系线

第一幕的问题是：人为什么肯跟一个连自己退路都没有的人走？第二幕把这份追随带进治理，迫使刘邦证明承诺是否适用于自己的军队。第三幕让玩家看到他既依靠他人，又会惩罚威胁；玩家此前给出的判断可以在这时被刘邦记起、质疑或拿来辩护。第四幕回到“猛士”与“选择”：刘邦仍需要别人有能力、有主见，却已经很难承受别人不受自己掌控。这个关系线作为重写假设，具体表达须由史料、场景和玩家选择检验，不能写成刘邦本人知道的后世评价。

## 正文写作方法

1. 先查清各事件的年代、史料出处、原文与争议，再完成此表；分析表写创作判断，不复制进角色台词。
2. 每幕从一个能听见、看见、触到的现场动作开场。自然让玩家知道眼前危险是什么、刘邦为什么此刻来电；不靠统一的“历史背景提示”格式。
3. 先写刘邦想做什么、另一个人如何阻拦或回应，再写玩家能以何种关系姿态介入。玩家选项的具体数量和方向由场景决定；选项像玩家的话，不出现“你赞不赞成”式问卷。
4. 让角色以行为承担矛盾。不要让刘邦总结“我能放人也能杀人”“我害怕失去”，而让他在眼前选择中说漏嘴、辩解、改口，玩家再指出他没有说出的部分。
5. 史实走向固定，分支体现关系温度、信息开放和角色如何处理玩家的判断。每幕结尾可以落在行动、余音、关系变化或一个自然未完的问题，不强制悬崖式钩子。

## 交付与复核

先按本表补充各幕具体史料与争议，再写完整正文；交付时同时给出分析表和正文，方便逐项审阅。逐句检查：不是假装第一人称的第三人称叙述；不了解史实的人能跟上当前处境；每个选项确实是玩家在说话；人物没有预知未来；项羽的“然后呢”节奏和表达没有被套给刘邦。用户审阅刘邦通过前，不开始韩信。
